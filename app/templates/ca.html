Where the keys are

Root key

{% if ca.root_key_present %}

The root key is on this server, encrypted with your CA passphrase. It's only needed to renew the intermediate in a few years, so the safest place for it is somewhere else.

Remove the root key from this server

After this, anyone who breaks into the server can't touch your root. Your backup becomes the only copy, so store it somewhere safe first. You'll upload it again when you renew the intermediate.

{% if not ca.root_key_exported %}

Download the backup above first. Removal is blocked until you have.

{% endif %}
{% else %}

The root key is not on this server. That's the safest setup. Keep your backup somewhere secure.

{% endif %}

Intermediate key

{% if ca.sealed %}

The intermediate key is locked. Enter the CA passphrase to let the CA issue and revoke certificates again.

{% else %}

The intermediate key is loaded, so this server can sign certificates on its own. It's stored in a folder only the CertForge user can read.

{% endif %}
