Where the keys are

Root key

{% if ca.root_key_present %}

The root key is on this server, encrypted with your CA passphrase. It's only needed to renew the intermediate in a few years, so the safest place for it is somewhere else.

Remove the root key from this server

After this, anyone who breaks into the server can't touch your root. Your backup becomes the only copy, so store it somewhere safe first. You'll upload it again when you renew the intermediate.

{% if not ca.root_key_exported %}

{% else %}

{% endif %}
