Install it

Pick your system. Browsers on Windows, macOS and ChromeOS use the system's trust list. Firefox keeps its own.

Windows
  1. Open the downloaded {{ slug }}-root-ca.cer file and choose Install Certificate.
  2. Select Local Machine, then Place all certificates in the following store, then Trusted Root Certification Authorities.
  3. Finish, and restart your browser.

Or, in an administrator PowerShell window:

Import-Certificate -FilePath "$env:USERPROFILE\Downloads\{{ slug }}-root-ca.cer" -CertStoreLocation Cert:\LocalMachine\Root
macOS
  1. Open the downloaded {{ slug }}-root-ca.crt file. Keychain Access opens. Add it to the System keychain.
  2. Double-click the certificate, expand Trust and set When using this certificate to Always Trust.

Or in Terminal:

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Downloads/{{ slug }}-root-ca.crt

The Apple profile works on a Mac too.

iPhone and iPad
  1. Open this page in Safari and tap Apple profile. Allow the download.
  2. Open Settings, tap Profile Downloaded near the top and choose Install.
  3. Go to Settings, General, About, Certificate Trust Settings and switch on full trust for {{ ca.root.subject }}. Without this step the profile is installed but not trusted.
Android
  1. Download the root certificate.
  2. Open Settings, search for CA certificate and choose Install a certificate, CA certificate. Menu names vary a little by phone.
  3. Confirm the warning and pick the downloaded file.

Chrome and most system apps will trust it. Some apps ignore certificates you add yourself. That's an Android rule, not a problem with your CA.

Linux

Debian, Ubuntu and Raspberry Pi OS. This downloads the certificate, checks its fingerprint against the one above, and installs it only if they match:

curl -fsSk https://{{ host }}/pki/root.crt -o /tmp/{{ slug }}-root-ca.crt && \
[ "$(openssl x509 -in /tmp/{{ slug }}-root-ca.crt -noout -fingerprint -sha256 | cut -d= -f2)" = "{{ ca.root.sha256 }}" ] && \
sudo cp /tmp/{{ slug }}-root-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates

Fedora, RHEL, Rocky and Alma, with the file already downloaded:

sudo cp {{ slug }}-root-ca.crt /etc/pki/ca-trust/source/anchors/ && sudo update-ca-trust

Chrome and Chromium on Linux keep their own list:

certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "{{ org }}" -i {{ slug }}-root-ca.crt
Firefox
  1. Open Settings, Privacy & Security, scroll to Certificates and choose View Certificates.
  2. On the Authorities tab choose Import and pick the downloaded .crt file.
  3. Tick Trust this CA to identify websites.

On Windows and macOS you can instead set security.enterprise_roots.enabled to true in about:config. Firefox then uses the system's trust list.

Java, curl, Python, Node and Docker

Java:

keytool -importcert -trustcacerts -alias {{ slug }} -file {{ slug }}-root-ca.crt -keystore "$JAVA_HOME/lib/security/cacerts" -storepass changeit

Tools that take a CA file, without changing the system:

curl --cacert {{ slug }}-root-ca.crt https://nas.home.arpa
export SSL_CERT_FILE=$PWD/{{ slug }}-root-ca.crt          # Python, Go, many others
export REQUESTS_CA_BUNDLE=$PWD/{{ slug }}-root-ca.crt     # Python requests
export NODE_EXTRA_CA_CERTS=$PWD/{{ slug }}-root-ca.crt    # Node.js
