Settings

How it's checked: a client proves it controls a name by serving a token over plain HTTP on port 80 of that name. Anyone who controls an allowed host can therefore get a certificate for it, so only allow names you'd trust that to. The CA's own name limits still apply on top.

Set up a client

Replace app.lab.example.com with the name the client should get a certificate for. Each client needs your root certificate (root.crt, from the trust page) so it can trust this address.

certbot 
REQUESTS_CA_BUNDLE=/path/to/root.crt certbot certonly --standalone \
  --server {{ acme_url }} \
  -d app.lab.example.com --register-unsafely-without-email --agree-tos{% if st.require_eab %} \
  --eab-kid KEY_ID --eab-hmac-key HMAC_KEY{% endif %}

certbot renews on its own after that (a timer or cron job comes with it).

acme.sh 
acme.sh --issue --standalone -d app.lab.example.com \
  --server {{ acme_url }} --ca-bundle /path/to/root.crt{% if st.require_eab %} \
  --eab-kid KEY_ID --eab-hmac-key HMAC_KEY{% endif %}
lego 
LEGO_CA_CERTIFICATES=/path/to/root.crt lego --server {{ acme_url }} \
  --accept-tos --email you@example.com --http -d app.lab.example.com{% if st.require_eab %} \
  --eab --kid KEY_ID --hmac HMAC_KEY{% endif %} run
Caddy 
{
  acme_ca {{ acme_url }}
  acme_ca_root /path/to/root.crt{% if st.require_eab %}
  acme_eab {
    key_id KEY_ID
    mac_key HMAC_KEY
  }{% endif %}
}
Traefik 
certificatesResolvers:
  certforge:
    acme:
      caServer: {{ acme_url }}
      email: you@example.com
      storage: /acme.json
      httpChallenge:
        entryPoint: web{% if st.require_eab %}
      eab:
        kid: KEY_ID
        hmacEncoded: HMAC_KEY{% endif %}

Start Traefik with LEGO_CA_CERTIFICATES=/path/to/root.crt in its environment.

Proxmox VE

Add the root certificate to each node's trust store first (cp root.crt /usr/local/share/ca-certificates/ && update-ca-certificates). Then, under Datacenter > ACME, add an account with the custom directory {{ acme_url }}{% if st.require_eab %} and your account key{% endif %}, and order the certificate from the node's System > Certificates page using the standalone (HTTP) challenge. The node's name must be in your allowed domains.
